한글 맞춤법 검사기

안내: 자주 틀리는 표현 258개와 되/돼·왠/웬·의존명사 띄어쓰기 규칙을 검사합니다.
정상적인 문장을 오류로 잡지 않도록, 문맥에 따라 달라지는 표현은 교정하지 않고 안내만 합니다.
검사 가능한 항목
맞춤법
  • 됬다 → 됐다
  • 어떻해 → 어떡해
  • 역활 → 역할
  • 오랫만 → 오랜만
  • 넣어봤읍니다 → 넣어봤습니다
되/돼, 왠/웬
  • 되요 → 돼요
  • 그러면 안되 → 그러면 안 돼
  • 왠일로 → 웬일로
  • 웬지 → 왠지
띄어쓰기
  • 할수있다 → 할 수 있다
  • 먹을것이 → 먹을 것이
  • 할줄알다 → 할 줄 알다
확인만 안내 (교정하지 않음)
  • 로서 / 로써
  • 결재 / 결제
  • 낫다 / 낳다
  • 반드시 / 반듯이

형태소 분석을 하지 않는 규칙 기반 검사기입니다. 등록된 표현은 확실하게 잡지만, 복합명사 띄어쓰기나 주술 호응 같은 문장 단위 오류는 검사하지 못합니다.
